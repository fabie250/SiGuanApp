# SiGuanApp · 丝衡智能耗材管理系统

3D 打印耗材智能管理全栈方案：安卓 APP + 网页客户端 + ESP32-S3 智能称硬件 + FastAPI 服务端。

## 系统组成

| 模块 | 技术栈 | 说明 |
|---|---|---|
| 安卓 APP | Kotlin + Jetpack Compose + Miuix | 主客户端，澎湃 OS 风格 UI（柔光玻璃 / 液态 dock / 渐变模糊） |
| 网页客户端 | HTML/JS (PWA) | 浏览器端管理界面 |
| ESP32-S3 固件 | Arduino / PlatformIO | 智能称：HX711 称重 + OLED 显示 + PN532 NFC 识别 + WS2812 |
| 服务端 | FastAPI + MySQL | 设备心跳 / 数据上报 / 耗材管理 API |

## 功能特性

- 耗材台账：增删改查、品牌/材质/颜色分类、低库存预警
- 智能称重：HX711 实时称重、去皮校准、NFC 识别耗材
- 待确认列表：滑动删除、批量操作、懒加载
- 设备管理：远程控制、系统操作、在线状态
- 澎湃风格 UI：柔光玻璃 / 清透磨砂双模式、顶部渐变模糊、液态 dock、随光而动的柔光玻璃
- 多设备适配：手机 / 平板
